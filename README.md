# LingoPlayer

个人使用的 macOS 本地播放器，可在识别到英文字幕后开启英语学习。SwiftUI / AppKit 界面、libmpv 播放、本地 MFA 逐词对齐、ECDICT 词典和 SQLite 缓存。

## 在当前 Mac 上使用

已构建的应用位于 `dist/LingoPlayer.app`，可在 Finder 中双击打开。应用包内含多尺寸 logo；构建结束会注册并刷新该应用包的图标信息。拖入视频，或使用 `⌘O` 选择文件。

本机构建将播放库放入应用包，MFA 和词库仍使用本项目的 `.runtime`。请保留项目目录；移动目录后需重新构建。此包是本机签名的个人技术原型，尚不是可独立分发的安装包。

首次从源码准备：

```bash
bash scripts/setup-runtime.sh --all
bash scripts/install-git-hooks.sh
bash scripts/build-app.sh
open dist/LingoPlayer.app
```

需要 macOS 14 或以上、Apple Command Line Tools、可用于首次下载依赖的网络和数 GB 空间。当前实测环境见 [验证记录](verification/REPORT.md)。安装脚本使用项目内 Miniforge，不修改 shell 配置。播放库来自 IINA 官方预编译依赖，MFA 和 FFmpeg 来自 conda-forge，ECDICT 来自原项目。

## 版本号与提交

[VERSION](VERSION) 是版本号的唯一来源。执行一次 `bash scripts/install-git-hooks.sh` 为当前仓库启用提交钩子；之后每次提交自动递增补丁号，例如 `1.1.0` → `1.1.1`。手动修改并暂存 `VERSION` 时采用指定值；提交失败后重试不会重复递增。有未暂存的版本号修改时停止提交，避免覆盖手动版本。钩子只额外暂存 `VERSION`，不会加入其他未暂存内容。

提交后运行 `bash scripts/build-app.sh` 构建对应应用；打包信息、播放界面版本号和请求标识均使用同一版本。已运行的旧应用需要退出后重新打开。新克隆仓库也需安装钩子；安装脚本会保留并提示已有的自定义钩子。

## 播放与学习

每次打开影片先进入普通模式。字幕先作为通用文字加载，法语、西班牙语、日语等字幕也可显示、浏览全文、搜索和点击时间码跳转。普通模式不启动 MFA 或词典查询，隐藏学习页、点词、逐词高亮、句子导航、回放和循环；对应菜单与快捷键也不可执行。自动联网搜索仍遵循已有设置。

“高级设置 → 播放”提供：

- **拖动进度条显示缩略图**：默认开启。只在拖动期间显示附近的低清画面与目标时间，松手只执行一次播放跳转。FFmpeg 独立取帧，不影响播放状态和音轨；缺少依赖、解码失败或超时时只显示时间。
- **学习模式启动方式**：自动／手动，默认自动。使用 macOS 本地 NaturalLanguage 跨字幕取样，过滤音效标记，至少 30 个有效字母且英文置信度达到 0.85；影片须可播放，且英文字幕至少有一个时间区间与影片重叠。文件名、轨道标签、影片题材和音轨语言不作为资格依据，也不等待逐词对齐。不会下载语言识别模型。

符合资格后，视频区域右上角显示“英语学习”开关，与顶部片名和操作面板同步显隐，全屏位置相同。自动策略会打开开关；手动策略可直接点击开启。开启时使用主题强调色，两种策略都可点击关闭。手动开启保留当前侧栏布局；字幕菜单保留“学习侧栏”入口。退出保留字幕、播放位置、播放／暂停状态和队列，并清理学习任务与独立窗口。当前影片的手动选择会保留到切换影片；修改启动策略会立即重新判断。


- 视频铺满主区域，保持原始比例；字幕悬浮在下方，底部操作面板显示在字幕上方，顶部《片名》随操作面板同步显隐。单击画面空白处显示／隐藏面板，不改变播放状态。播放时空闲 3 秒自动隐藏，暂停、操作面板或配置弹层时保持显示。
- 音量调节显示当前百分比、增减值和动态音量条，面板与音量弹层的喇叭图标随音量变化。快进／后退、倍速、播放／暂停、句子导航、循环和字幕显示等快捷键在画面上短暂显示操作结果；连续操作会刷新提示。
- 打开视频、字幕导入／搜索、倍速、音量、播放列表和播放设置都在底部面板。播放设置包含字幕偏移、句尾多播、音轨与逐词任务状态；“高级设置”打开完整设置。
- 自动加载同目录同名字幕（例如 `film.en.srt`、`film.zh.srt`）与内嵌文字字幕；“字幕”菜单支持选择其他候选、手动导入及在线搜索。
- 支持 SRT、ASS/SSA、VTT，保留全部合法文字字幕；学习模式下双语文件按中英文行拆分。单独导入英文保留已选中文字幕；重开影片时，自选中文优先于双语主文件附带的译文。中文和英文分别按自己的时间显示，可在播放设置中用上下箭头独立调整偏移，每次 0.1 秒。停止调整 1 秒后生效并保存，关闭弹层仍会应用；正值表示字幕推迟。
- 等待生效期间点击“重新准备逐词高亮”会保留调整值和原定生效时间；直接退出应用也会保存最后选定的偏移，供下次打开影片恢复。
- 播放设置显示“等待生效／已生效”；“联动调整中英文”让两种字幕同步增减并保留原有时间差，“全部归零”同时重置两种偏移，仍在停止调整 1 秒后应用。
- 倍速支持 0.5、0.75、1、1.25、1.5、2、2.5、3×，菜单和快捷键共用档位。音轨优先恢复用户选择，其次采用片源默认音轨，不默认优先英语。
- 音量、倍速和普通窗口大小自动记忆，重启后恢复；全屏不会覆盖普通窗口大小。恢复窗口时会适配当前屏幕的可用空间。
- 操作面板的“无黑边”图标开关：非全屏窗口按影片显示比例缩放，兼顾侧栏宽度、旋转视频和非方形像素，完整保留画面。拖动时维持比例，开关和窗口大小自动记忆；全屏沿用屏幕比例，退出后恢复。它不移除影片本身编码进去的黑边。操作按钮始终保持单行；自由缩放窗口与无黑边窗口共用视频区 680×360 pt 的尺寸下限，展开侧栏时另计侧栏宽度。自由缩放窗口可以缩到与无黑边窗口相同的尺寸，关闭无黑边不会放大窗口。若竖屏或超宽视频无法在当前屏幕内同时满足影片比例与最小工具栏尺寸，优先完整显示按钮和画面，允许保留黑边。
- 操作面板提供全屏／恢复图标开关，图标状态跟随实际窗口；全屏与无黑边切换显示和快进操作一致的画面反馈，全屏提示在切换完成后显示；无黑边、播放／暂停、音量、字幕等工具悬浮时显示功能和当前状态。
- 相机图标截取当前视频和当前显示的字幕，不含操作面板、片名和侧栏。默认仅复制到系统剪贴板，可直接粘贴到其他应用；“高级设置 → 截图”可复选剪贴板、PNG 文件，并选择保存文件夹。只选剪贴板时不生成截图文件。保存完成后显示具体目的地；文件写入失败时仍可复制到剪贴板，并分别提示结果。
- 播放设置的“字幕外观”页可分别调整中英文字号、背景不透明度和距底部距离，预览与视频字幕同步更新，自动保存并用于后续视频。距底部始终以实际视频画面的底边为准，全屏或窗口中的黑边不计入距离，截图采用相同位置；侧边黑边也不计入字幕排版宽度。空间不足时限制上移距离以保留字幕。“恢复默认”仅重置外观。字幕变大或上移时，操作面板优先放在字幕上方，空间不足时移到字幕下方；两侧均放不下时，面板仍保留在窗口内、片名下方，显示期间可能覆盖部分字幕。
- 设置页切换保留未保存的表单内容；关闭设置后放弃尚未保存的运行环境改动。选择视频、字幕和运行环境文件时，窗口异步打开并复用，取消不改变当前播放或设置；文件窗口内的输入不会触发播放快捷键。
- 播放设置按需创建字幕外观页，滑杆继续按原单位取值；窗口缩放合并重复的绘制尺寸更新，并在 AppKit 拖动事件循环中继续提交视频。顶部渐变交给 Core Animation 缩放。
- 打开视频立即播放。进入英语学习模式后，MFA 在后台使用本地音频和已有英文字幕生成单词时间戳；未准备或失败的片段显示整句，仍能点词，不使用平均分配的假时间。
- 默认词卡随发音更新。点击英文单词暂停并锁定；普通播放按钮或 `⌘P` 继续播放时保留词卡。
- 高级设置 → 播放中的“暂停即选中”默认开启：英语学习模式下主动暂停时，若有高亮单词，会像点词一样打开并锁定该词卡；无高亮或关闭开关时只暂停。句子回放自动结束仍保留原锁定词卡。
- 锁定词卡后，词头旁的左右按钮或 `⌘←`／`⌘→` 可切换本句中的相邻单词，跳过标点，到句首／句尾禁用，不跨句、不跳转播放位置。这两个动作仅锁定时可用，可在快捷键设置中改绑；已有自定义绑定优先保留。
- “继续学习”或 `⌘Return` 退出循环、解除锁定并恢复播放；“回放本句”或 `⌘R` 退出循环，播放选中台词一次后暂停，保留词卡。
- 回放与单句循环默认在字幕终点后多播 0.8 秒，避免字幕句尾偏早而截断语音。在滑杆图标的“播放设置”中可调整“句尾多播”（0–3 秒，按视频保存）。它不改变字幕偏移或逐词时间；若带入下句，可调小。练习和回放结束暂停时保留当前练习字幕，继续播放或跳转后恢复跟随。
- 学习区右上角可分离窗口；有第二屏时优先放到第二屏，关闭学习窗口后回到侧栏。
- 词卡显示词形、原形（词库提供时）、音标、词典释义、当前中英台词。词典释义不代表对当前语境的自动消歧。

图片字幕、烧录字幕暂不参与学习。不提供无字幕听写、自动翻译和流媒体站点接入。ASS 被转换为纯文字，不复刻原文件的动画、位置或字体特效。一个文本行中混排的中英译文可能需要先整理为分行字幕。

## 字幕全文与精听

右侧“字幕”页签显示可搜索的全文。普通模式保留原始字幕文本，时间码执行普通跳转。学习模式以英文为主行，中文按两种语言各自偏移后的时间重叠关联；一条中文可对应多个英文句子，没有对应英文的中文仍单独保留。仅中文或仅英文也能浏览。

- 搜索中英文采用字面匹配，英文忽略大小写；显示匹配数量，可清除搜索。全文不提供点词学习，点词仍在视频区字幕中进行。
- 点击时间码跳到该句开头，保留播放／暂停与锁定词卡。正在单句循环时，点击另一条英文时间码会把循环目标改为该句；点击独立中文行会退出英文循环并定位。
- 默认突出当前字幕并滚动跟随。滚轮、滚动条或列表导航键，以及输入搜索，会暂停跟随；“回到当前句”清除搜索并恢复跟随。清除搜索本身不会打断阅读位置。
- 更换视频或英文字幕清除搜索和浏览状态；调整偏移重新关联译文和跳转时间。独立学习窗口可与主窗口的字幕全文同时使用。

以下精听功能仅在学习模式可用。播放控制区的循环按钮或 `⌘⇧R` 从当前英文句首开始连续循环。对白间隙可点击全文中英文行的“循环此句”按钮。范围使用英文偏移后的起止时间，加上独立的句尾余量，并裁剪到视频有效范围。

- 循环保持当前倍速，无句间等待；普通播放／暂停保留目标。上／下一句或英文全文定位切换循环目标，同时保留播放状态和锁定词卡。
- 关闭循环保留当前位置与播放状态。“继续学习”退出循环并解锁；“回放本句”执行原有的一次回放。
- 拖动进度条、前后跳转 5 秒、更换视频或音轨、更换英文字幕、修改英文偏移都会退出循环。中文偏移不改变循环目标。
- 片尾循环优先于自动连播，不进入下一部，也不记为自然看完。循环、搜索和滚动状态不随重启恢复。

普通模式提供“显示字幕／无字幕”；学习模式提供“双语／英文／无字幕”菜单，`⌘B` 按此顺序循环。选择自动保存，适用于后续视频。无字幕模式隐藏悬浮字幕，视频尺寸保持不变；全文、对齐和词卡仍正常更新。这只控制应用绘制的文字字幕，不能隐藏视频画面内烧录的文字。

## 播放列表与续播

右侧的“学习／字幕／播放列表”页签共用侧栏空间。新安装默认收起，已有的侧栏显示偏好继续保留。底部播放列表按钮直接展开侧栏并切到播放列表；点词展开学习页，“继续学习”保持侧栏展开，可手动收起。学习区分离后主窗口自动显示播放列表，可自行切换到字幕全文；切回“学习”可以定位独立窗口或收回，关闭独立窗口后自动回到学习页签。

播放区域右下角以小字悬浮显示当前应用版本号，与操作面板同步显隐；底部有黑边时显示在黑边内，不占用侧栏或改变视频布局。

- `⌘O` 多选、拖入多个文件或 Finder 批量打开：追加并播放本次文件中按文件名自然排序的第一项（例如第 2 集排在第 10 集之前）。同一路径和符号链接去重。
- 播放列表中的“添加”只追加，不打断当前视频；当前没有视频时开始播放。
- 双击列表项播放，拖到另一项上方调整顺序，拖到列表底部移至末尾。可通过右键菜单在 Finder 中定位文件。
- 移除非当前项不影响播放；移除当前项播放原来的下一项，没有下一项则停止。清空列表停止播放。以上操作均不删除文件。
- “自动连播”默认开启，自然播完进入下一部；队尾停止、不循环。缺失或损坏文件标记后跳过，没有可用后续文件时停止并提示。
- 未看完的文件续播，已自然播完的文件再次打开从头开始。退出会保存列表顺序、当前文件和观看位置；重新启动恢复时保持暂停。
- “回放本句”到片尾也只暂停，保留词卡，不触发下一部。普通拖动到视频终点也不会当作自然播完。

## 快捷键

“设置 → 快捷键”支持按键录入、清除、单项恢复和全部恢复默认。按 `Esc` 取消录入；冲突会提示对应操作，必须先清除旧绑定。修改立即保存，菜单和按钮提示同步更新。

| 操作 | 默认按键 |
|---|---|
| 播放／暂停 | `⌘P` |
| 回放本句 / 继续学习 | `⌘R` / `⌘Return` |
| 后退 / 前进 5 秒 | `←` / `→` |
| 上一句 / 下一句 | `⌥←` / `⌥→` |
| 降低 / 提高音量 | `↓` / `↑`（每次 5%） |
| 降低 / 提高倍速 | `[` / `]`（0.5、0.75、1、1.25、1.5、2、2.5、3 倍） |
| 上一部 / 下一部 | `⌘⇧←` / `⌘⇧→` |
| 学习 → 字幕 → 播放列表 | `⌘L` |
| 开启 / 关闭单句循环 | `⌘⇧R` |
| 双语 → 英文 → 无字幕 | `⌘B` |
| 全屏／恢复窗口 | `⌃⌘F` |
| 开启／关闭无黑边 | `⌥⌘B` |
| 截图 | `⌥⌘P` |

普通模式的 `⌘L` 仅在字幕／播放列表之间切换，`⌘B` 切换显示／隐藏字幕；学习动作的自定义绑定仍保存，进入学习模式后生效。

这些是应用内快捷键，播放器和独立学习窗口均可用。文本编辑、中文输入组合态、设置、弹窗和字幕调节期间让位于原生键盘操作。打开文件 `⌘O`、导入字幕 `⌘I`、设置 `⌘,` 和系统编辑快捷键保留。

按钮、进度／音量滑杆及字幕列表获得焦点后，播放器快捷键仍有效，包括自定义的空格播放／暂停。离开搜索等输入框，点击视频或其他非输入区域后，会结束文字输入并恢复快捷键；在输入框内继续保留空格、方向键及中文输入法行为。

升级时，如果已有自定义绑定占用了新增动作的默认键，保留原绑定；冲突的新动作暂不绑定，并在快捷键设置页提示。可以清除旧动作的绑定后再分配，或为新动作选择其他按键。

上／下一句使用播放位置与英文字幕偏移定位，保留播放或暂停以及词卡锁定状态。在对白间隙，上一句返回最近的前一句、下一句前往后一句；正在一句内时定位到相邻句。不跨影片，无可到达英文字幕时禁用。

## 在线字幕配置

在设置中填写 OpenSubtitles API Key；如下载需要登录，在同一页输入该服务的用户名和密码。API Key 和登录 token 存入 macOS 钥匙串，密码不持久化。

搜索使用文件哈希、片名、年份和季集信息。唯一文件哈希匹配可自动采用；不确定的匹配展示候选供选择。找不到或服务不可用时仍可播放，并可导入本地字幕。所选字幕及各语言偏移随片源保存。没有配置 API Key 不影响本地功能。

在线服务会收到搜索所需的文件哈希与片名信息；视频、音频不上传。字幕文件和词典在准备后可离线使用。首次安装模型和词库需要联网；播放期间不会自动下载模型。

## 数据与实现

进度预览最多每 250 ms 启动一个 FFmpeg 进程、同时仅一个任务，拖动请求只保留最新目标；以 2 秒分桶做内存 LRU 缓存，最多 64 张且包含解码像素在内不超过 16 MiB。最长边 240 像素，单线程解码、2 秒超时，不预生成整片、不保存预览图片。松手、关闭开关或停止播放取消待处理工作；切片清空缓存，旧进程退出后才允许启动新任务。验证入口为 `bash scripts/run-playback-mode-smoke.sh`，详见 [本轮验证记录](verification/PLAYBACK-MODES-2026-09-28.md)。


默认数据目录：`~/Library/Application Support/LingoPlayer/`。

| 文件或目录 | 用途 |
|---|---|
| `library.sqlite` | 观看位置、时长、完成状态、单个队列顺序与当前项、音轨、字幕路径、偏移、逐句对齐缓存 |
| `interaction.json` | 快捷键、自动连播和视频字幕显示偏好；与运行环境设置独立 |
| `viewing.json` | 音量、倍速、普通窗口大小、字幕外观、偏移联动、进度预览开关和学习启动策略 |
| `settings.json` | 本地依赖路径与自动搜索设置；不含密钥 |
| `MFA/pretrained_models` | 本地声学模型及发音词典 |
| `Subtitles` | 抽取的内嵌字幕和下载字幕 |
| `AlignmentJobs` | 对齐临时文件，任务结束后清理 |
| `alignment-metrics.jsonl` | 每批处理耗时、子进程峰值内存、词数与失败数 |

`LINGOPLAYER_DATA_DIR` 可覆盖数据目录；`LINGOPLAYER_RUNTIME` 可指定依赖根目录。自定义运行环境也可在设置页配置。更换 libmpv 路径后需重启。

SQLite 从 v1 增量升级至 v2，仅新增队列与进度表，不删除旧观看记录和对齐缓存。v0.3 沿用数据库 v2，不新增表。旧设置继续使用；缺失的交互偏好采用默认值。快捷键、连播和字幕显示设置不重启播放器或对齐任务。

`PlayerCore` 提供字幕解析、独立时间轴、学习状态、词典、字幕服务、队列、动作与快捷键规则、EOF 策略和存储。`CMpv` 仅适配 libmpv 的稳定 C API，播放器控制和视频渲染分别运行在独立串行队列，AppKit 界面运行在主线程。`LingoPlayer` 管理界面、双窗口和后台调度。`DictionaryLookupController` 通过可注入的 `LearningContentProvider` 管理查词、取消与缓存，主模型传入当前选择；文件偏好写入与 SQLite 连接独立。相关故障回归与重构说明见 [代码质量审查](verification/CODE-QUALITY-2026-09-28.md)。

对齐使用独立可取消进程，一次优先准备当前播放位置附近约 30 秒的字幕。缓存按片源标识、字幕内容、音轨、英文偏移、模型版本和处理脚本版本隔离，逐句保存。跳转到尚未准备的新片段会调整队列。故障片段保持整句；基础设施故障会停止自动重试并显示状态。

### v0.3.1：词卡、侧栏与任务诊断

- 学习区右上角 **×** 关闭词卡：解除锁定并停止查词，不改变播放、单句循环或视频单词高亮。词卡会保持关闭；再次点击视频字幕单词可恢复并暂停锁词。
- 工具栏侧栏按钮或 **⌘⌥L** 展开／折叠整个右侧区域。**⌘L** 继续按学习 → 字幕 → 播放列表循环，并展开侧栏。折叠保留当前页签、搜索和浏览位置。
- 词卡关闭、侧栏折叠分别保存，重启仍保持。点词会展开学习页；已有独立学习窗口时直接定位该窗口。关闭独立窗口不会强制展开主侧栏。
- 逐词准备失败时，播放设置提供 **查看详情** 和 **重试**。重试重新检查 Python、FFmpeg、MFA、模型及输出目录，不会清除已有高亮结果。部分句子无法对齐时保留整句，继续处理其他句子。
- 默认 Python 优先使用项目 `.runtime/aligner/bin/python`，用户明确指定的路径继续保留。
- 诊断仅保存在本机数据目录的 `AlignmentFailures`：最多 20 条、总计 20 MB；包含任务配置、退出码、完整进程输出与 MFA 文本日志，不保存提取音频。单条超出总限额会标记截断。可从详情窗口在 Finder 中定位。
- 播放进度最多 10 Hz 刷新；字幕按内容变化更新。原始播放时间仍用于高亮和循环判断。缓存及保存操作在后台执行，切片与退出时完成必要落盘。
- 播放状态变化时才重新读取片源、时长、暂停和画面尺寸等信息；高亮与循环仍使用 30 Hz 原始时钟。逐词高亮固定字宽并复用句子测量结果，避免高亮切换挤动换行；学习词卡复用可选择、可复制的原生文字控件。后台对齐以较低调度优先级运行，并限制 OpenBLAS／OpenMP 等数值库为单线程，减少与播放争抢资源；已有逐词缓存继续有效。

学习模式资源优化的测量结果与局限见 [2026-09-29 验证记录](verification/LEARNING-PERFORMANCE-2026-09-29.md)。
