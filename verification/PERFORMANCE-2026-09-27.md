# 播放界面性能优化 · 2026-09-27

LingoPlayer 0.3.1 build 8。基准为 `537ff6b` 的播放实现，只加入与优化版一致的本地性能计数；使用 Release 构建。测试机器：Intel Mac，macOS 15.8.

## 改动

- 操作面板隐藏后移出界面树，避免继续按播放进度构建控件；显现时读取最新播放状态。弹层和拖动仍阻止自动隐藏。
- 字幕全文不在前台时仅记录播放时间，停止持续发布高亮和滚动事件，也不更新原生表格。保留表格实例和阅读位置，展开时立即同步状态。
- 字幕流式排版缓存子视图尺寸与行布局，宽度、字体尺寸或间距变化时重新计算，避免同一轮布局反复测量每个单词。
- 锁定单词单独发布给字幕界面；词典查询结果和加载状态不再触发整条字幕重绘。
- 视频解码、播放器时钟、逐词时间和回放范围算法保持原有实现。

## 同条件对比

采用本地 30 秒、960 像素宽的测试片段，每组使用 5,000 条英文及 5,000 条中文、180 个明确标记的合成单词时间。每种状态先稳定 1 秒，再采样 120 次主线程唤醒，约 6–7 秒。每组都确认持续播放、字幕数量一致、超过 20 个不同单词高亮及持续视频绘制。

CPU 使用进程用户态加系统态 CPU 时间除以墙钟时间，一个核心满载为 100%；不含 WindowServer 和其他进程。文字测量按实际采样时长归一化。单次短场景受温度和系统负载影响，不代表所有片源或整机功耗。

| 场景 | CPU：优化前 → 后 | 单词尺寸测量／秒：前 → 后 | 测量次数下降 |
|---|---:|---:|---:|
| 沉浸播放 | 41.2% → 22.9% | 842 → 123 | 85.4% |
| 显示操作面板 | 35.0% → 34.3% | 878 → 125 | 85.7% |
| 学习侧栏 | 64.6% → 61.9% | 1608 → 121 | 92.5% |
| 字幕全文 | 34.1% → 38.7% | 863 → 125 | 85.5% |

沉浸模式的隐藏面板构建次数从一组 53 次降为 0。前三组的后台全文原生表格更新从 9–11 次降为 0。学习模式字幕界面构建从 92 次降至 48 次。

收益最明显的是沉浸播放；展开面板和学习栏的 CPU 改善较小，字幕全文场景此次 CPU 从 34.1% 升至 38.7%，不能宣称它获得 CPU 改善。该场景减少了文字测量，但视频解码、原生表格和合成开销仍在。本轮结论限于减少明确的界面重复工作。

测试准备阶段发现“播放已就绪”早于字幕和音轨加载结束，后续加载会清空合成词时间。最终对比等待加载完成，并核验高亮工作量；此前未满足条件的探索结果不计入本表。测试窗口忽略实体鼠标，防止悬停或点击改变测试状态。

## 真实片源按钮响应

本机反馈的 1080p HEVC 片源及 5,000 条字幕，各测暂停、播放、后台对齐；每组 60 次原生鼠标操作，共 360 次。每次从当前辅助功能几何重新定位悬浮按钮，定位发生在计时之前；校验实际动作序列，记录界面反馈和 mpv 暂停确认。

| 场景 | 界面 P95 ms | 界面最大 ms | 暂停确认 P95 ms |
|---|---:|---:|---:|
| user-film / paused | 38.0 | 55.5 | — |
| user-film / playing | 48.5 | 59.4 | 41.0 |
| user-film / aligning | 41.7 | 50.0 | 37.2 |
| 5000 / paused | 33.6 | 34.7 | — |
| 5000 / playing | 41.5 | 71.0 | 42.4 |
| 5000 / aligning | 43.5 | 70.7 | 42.2 |

六组均满足界面 P95 ≤100 ms、最大 ≤250 ms、暂停确认 P95 ≤250 ms。两组后台对齐的最终状态均为“后台准备逐词高亮”。此处测量的是应用反馈，不是硬件输入或显示器扫描延迟；HEVC 解码跳转单独记录。

## 回归与交付

- Swift 64/64、Python 10/10。
- 悬浮布局与原生点击 29/29；包括长字幕、无字幕、显隐后点词、设置和全屏截图。
- 精听与恢复 56/56；新增隐藏全文停止高亮刷新、展开恢复当前高亮与保留手动阅读位置。句尾补偿、偏移、高亮和 20 次片尾循环通过。
- 原生快捷键焦点检查 35/35；独立检查输入框、按钮、滑杆、独立学习窗口，保持真实焦点而不在每次操作前重置。
- 高层精听命令测试先取得窗口焦点；句尾夹具等待音轨发现结束再注入。全屏截图等待窗口服务器的可捕获画面，空闲隐藏检查显式模拟移出悬停区。保留断言，消除测试准备和窗口过渡造成的不确定性。
