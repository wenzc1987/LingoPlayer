# 第一轮技术原型验证记录

验证时间：2026-09-25 至 2026-09-26（Asia/Shanghai）。

当前已交付可运行的本机 Release 应用，核心播放、双语字幕、MFA 逐词时间、词卡、双窗口和缓存流程已跑通。**逐词准确率验收尚未完成**：当前没有独立人工词起点标注，也没有完成三类真实影视片段的抽检。以下“157 词产出”仅表示对齐成功，不表示 157 词均满足 ±200 ms。

## 已验证的行为

- `bash scripts/test.sh`：**26 项 Swift 测试及 6 项 Python 测试通过**。覆盖独立时间轴、重叠字幕、偏移、SRT/ASS/VTT、锁定状态、词典原形、SQLite 持久化、文件哈希、候选排序、进程取消、服务错误与逐词输出校验。
- Release 应用真实窗口验证：MP4 外置字幕、MKV 内嵌双语字幕；可播放、查询本地词典、点词暂停、普通播放保留锁定、本句回放到边界后暂停、恢复跟随、倍速及跳转。
- GUI 检查分别为 MP4 21 项、MKV 22 项，均通过；包含真实 OpenGL framebuffer 的非黑画面检查。
- 学习窗口分离后共享选词状态，关闭后侧栏恢复。未在第二块实体显示器上验证摆放位置。
- 实际加载 5 句中英文字幕。修改中文偏移不改变英文显示。手动导入双语 ASS 后两种语言均可用。
- MFA 成功产出全部 157 个单词区间，播放器时间驱动高亮。缓存恢复无需再次对齐。改变英文偏移、音轨或视频后不会沿用旧时间戳。
- 缺少模型时仍能播放和点词；无字幕时仍播放，手动导入后恢复学习。词典缺失/缺词在核心测试中验证。
- 断网、HTTP 401、HTTP 503、下载密钥隔离使用 URLProtocol 模拟测试，**未使用真实 OpenSubtitles 账号请求**。

GUI 自动验证通过模型的方法触发与按钮相同的动作，并检查真实 libmpv 状态及 AppKit 窗口状态；不是鼠标点击坐标的可用性测试。具体每项结果保存在 `results.json` 及 `local/ui-mp4/smoke.json`、`local/ui-mkv/smoke.json`。

## 本机性能实测

| 测量 | 结果 | 边界 |
|---|---:|---|
| 新进程模型加载合计 | 1.240 秒 | Kalpy 导入 + 解压 + 读取真实声学权重和树；未清空系统文件缓存 |
| 其中声学权重与树读取 | 0.559 秒 | 不含特征提取、词典导入或对齐 |
| 该进程峰值内存 | 219.3 MB | 单独模型加载进程 |
| 59.635 秒音频一次完整对齐 | 36.342 秒 | 157 词，5 句，0 失败句 |
| 上述对齐子进程峰值内存 | 453.7 MB | `getrusage(RUSAGE_CHILDREN)`，不是播放器与全系统合计 |
| 播放器首次后台批次 | 约 22 秒 | 当前附近 4 句、126 词 |
| 剩余批次 | 约 19 秒 | 1 句、31 词；每批独立启动进程仍有固定开销 |
| 5 句缓存恢复 | 约 4–7 毫秒 | 本机 SQLite 缓存；后续运行精确值见 JSON |

后台处理时普通播放、回放、跳转、倍速和窗口操作均通过状态检查。未进行长片持续播放的掉帧统计、温控/电池测试或大规模片库压力测试。

## 排查与修复

1. 当前机器的 Homebrew 构建路径需要完整 Xcode，改用官方 IINA 预编译播放库及项目内 conda 环境。
2. MFA 新版依赖组合有兼容问题，固定 MFA 3.3.9 / Kalpy 0.9 / SQLAlchemy 2.0，并保存完整环境清单。
3. MFA 使用相对临时目录时可能找不到最终对齐归档，进而报 `word_interval_temp` 不存在；统一绝对路径后已在命令行及真实应用验证。
4. 首次原生启动发现 `NSOpenGLView` 初始化崩溃，改用正确的指定初始化方法后已验证 Release 正常运行。
5. 每批导入完整发音词典带来明显开销，改为保留原发音及概率的所需词条子集，不生成虚构发音或词时间。

## 尚待完成的验收

| 待验收项 | 缺少的证据 / 下一步 |
|---|---|
| 真实影视逐词精度 | 提供清晰对白、快速对白、背景音乐三类片段与英文字幕；独立人工标注至少 100 词，清晰对白达到 90% 的起点误差 ≤200 ms。当前不填写虚构准确率。 |
| 在线字幕实际匹配 | 配置个人 OpenSubtitles API Key / 所需登录，使用真实影片验证哈希命中、片名回退、错误版本候选与下载配额。已实现接口及错误处理，尚未完成线上实测。 |
| 双屏实物检查 | 在外接显示器上核验分离窗口位置、缩放和关闭恢复。当前检查覆盖同机双窗口状态。 |
| 复杂素材与长时间使用 | 更多编码、图片字幕跳过、短句/音乐/多人重叠及长片后台准备速度；错误版本需由用户选择正确字幕或调整偏移。 |

人工标注模板可由 `scripts/create-annotation-template.py` 导出，它只导出字幕文本并留空词起点，不把模型预测当参考答案。`scripts/evaluate-alignment.py` 将未产出的词计为失败，并分别报告三类场景。
