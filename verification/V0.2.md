## 关键边界

- `eof-reached` 是连播判断来源；每次加载使用独立 generation 和 mpv playlist entry ID。旧片源快照、旧结束事件及重复 EOF 不切换新片源。
- 自然结束后只进入一次下一部；损坏文件和缺失文件标记并跳过。队尾停止；全部不可用时停止并提示。关闭连播保持当前视频。
- 片尾本句回放暂停并保留词卡，不连播、不写入“自然看完”。直接拖动到片尾也不会连播。自然看完的影片再次打开从零播放。
- 快速切片清除字幕、词卡与旧对齐输入，取消旧进程。修复了取消后播放时钟可能再次调度上一部影片对齐输入的问题。
- 上／下一句在英文偏移及对白间隙中定位，保留暂停与锁词，不跨片源。
- 所有载入先暂停。恢复位置的 seek 在解除暂停前发送；启动恢复一直保持暂停，避免短暂发声。
- SQLite v1 → v2 仅新增 `queue` / `progress` 表。实际建立 v1 数据库后升级、重开，旧观看记录和对齐缓存仍在。
- `interaction.json` 独立保存快捷键与连播偏好；缺字段使用默认值。偏好更新不重新配置播放或对齐任务。

## 复现

```bash
bash scripts/test.sh
bash scripts/build-app.sh
bash scripts/run-interaction-smoke.sh
bash scripts/run-smoke.sh "$PWD/verification/local/clear.mp4" "$PWD/verification/local/v02-regression-mp4"
bash scripts/run-smoke.sh "$PWD/verification/local/embedded.mkv" "$PWD/verification/local/v02-regression-mkv"
codesign --verify --deep --strict dist/LingoPlayer.app
```

后两项使用 v0.1 已生成的本地验证视频；缺失时先运行 `scripts/prepare-validation.py`。GUI 自检使用全新隔离状态目录；两次恢复测试共享同一个测试目录，不修改个人观看数据。
