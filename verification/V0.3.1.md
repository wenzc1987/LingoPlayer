# LingoPlayer 0.3.1 验证记录

日期：2026-09-26。环境：当前 Intel Mac，macOS 15.8，Intel i5-8259U，8 GiB RAM，Swift 6.2.4；本项目 libmpv / FFmpeg / MFA / ECDICT 本机依赖。应用为本机签名 Release，不是独立分发安装包。

## 实现范围

词卡关闭、侧栏折叠及两个独立持久化偏好；新增 ⌘⌥L；关闭后的点词恢复、双窗口路由和页签切换；结构化逐词任务状态、错误详情与重试；本地限额诊断；后台进程取消等待；状态分离、字幕索引和分词缓存；后台 SQLite / JSON 保存；独立视频绘制队列。

按钮补测期间，采样进一步发现 NSOpenGLView 会在窗口布局中隐式等待 CGL 渲染锁；已改为普通 NSView 承载上下文，绘制和尺寸更新通过串行队列异步协调，避免该主线程等待。实际 framebuffer、侧栏尺寸与双窗口回归通过。

SQLite 保持原有四张表和 user_version=2。字幕编码不写入分词缓存，旧字幕缓存仍可解码；旧交互设置缺字段默认显示词卡、展开侧栏。新默认快捷键与旧绑定冲突时保留旧绑定。

## 测量方法

保留 v0.3 的源代码和应用，仅加入内部计时探针作为基准。新旧版本均使用真实反馈片源，在上次反馈位置附近，另加 5,000 条合成字幕场景。每种字幕场景分别测试暂停、播放、后台对齐，每组目标 60 次操作。

按键经 NSApp 事件队列、真实本地键盘路由和统一动作入口执行；计时从事件提交开始，分别记录动作开始、原生视图刷新与 mpv 实际暂停／定位确认。视图探针携带动作序号，以免 SwiftUI 把恒定探针视为无需更新。对被遮挡的测试窗口显式绘制探针；该指标是应用界面更新延迟，不是显示器的物理扫描延迟。跳转的解码定位耗时单独记录，未作为暂停确认或界面反馈替代值。

原始计时、片源路径、字幕及错误日志保存在被 Git 忽略的 `verification/local` 下。公开记录仅保留汇总，不复制影视台词。

## 原始错误与独立验收

截图对应旧版后台子进程异常退出，不等于 Python 无法启动。旧失败目录和完整日志已被清理，单凭截图无法还原当时具体异常。当前片源复现结果应与诊断能力新增分别记录。

真实影视逐词精度人工抽检、OpenSubtitles 线上联调继续独立验收；本次交互、合成字幕和自动化性能测试不能代替这些结论。

## 真实片源错误复现

在反馈片源的原观看位置约 2,075 秒重新运行。Python / FFmpeg / MFA 正常退出，首批 12 句约 24 秒完成，生成 72 个词时间戳，子进程峰值内存约 412 MiB。1 句返回“出现未识别词，保留整句字幕”，其余结果正常，调度继续下一批。该失败的完整 MFA 日志与请求摘要已保存到隔离测试数据目录；临时音频清理完成。

## 回归与失败注入

- 56 项 Swift 测试、10 项 Python 测试通过；覆盖兼容解码、字幕时间索引、快捷键冲突、诊断条数／总字节限额、完整 stderr、超长中文日志截断后仍可读取、进程非零退出、超时以及取消时子进程停止。
- 原生词卡／侧栏／诊断／重启检查 19 项，精听与字幕导航检查 44 项，队列与快捷键检查 39 项，MP4 / MKV 播放和真实 MFA 检查 43 项通过。
- 原生检查包含词卡关闭后不自动出现、点词重开、锁定解除但循环保留、折叠后的页面／搜索保留、独立窗口组合、重启暂停恢复、缺失 Python / 模型、查看日志、恢复后重试以及取消后无音频工作目录。
- Python 注入覆盖 FFmpeg 非零退出、空音频、无效单句不阻断有效句、MFA 非零退出。Swift 取消测试包含忽略 SIGTERM 的子进程，确认调用返回后心跳已停止。
- 片尾循环 20 次，不误连播；5,000 条字幕准备约 149 ms，搜索含防抖约 214 ms，播放时主线程检查最长间隔约 71 ms。
- 原生绘制快照检查卡片关闭、侧栏折叠后的视频宽度、窗口缩放与持续绘制；自动 avsync 指标通过，人工口型同步仍未单独检查。
