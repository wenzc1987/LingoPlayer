## 功能边界

字幕全文使用两种语言各自偏移后的半开时间区间关联；保留未关联中文，一对多译文不丢弃。排序、关联、搜索分别在内容或查询改变时计算，播放时钟只查询可复用的时间索引。搜索在后台执行并忽略旧任务的结果。原生 NSTableView 只创建可见行，支持滚轮、滚动条与列表导航键暂停跟随。

循环状态独立于锁定词卡和一次回放。循环结束通过实际 mpv 时钟及 EOF 检测，跳回偏移后的句首；范围裁剪到有效视频时长。每次加载和跳转都有标识，旧片源或旧循环定位的快照不会覆盖新状态。循环定位若持续失败，会退出并暂停，显示明确提示。

关闭循环不改变播放意图或位置；全文英文定位及上／下一句保留播放意图并更新循环目标。独立中文行没有英文循环目标，定位时退出循环。拖动滑杆开始即退出循环。继续学习、一次回放、字幕替换、英文偏移、音轨和片源切换遵循各自的退出规则。

字幕显隐仅影响视频区文字与等待提示，保留布局和后台学习更新。英文模式保留中文原占位但不显示；无字幕模式不接收视频字幕点击。全文与词卡保留两种语言内容。

## 兼容与数据

SQLite 保持 v2，未增加数据库表、修改观看记录结构或改变对齐缓存键。已有数据库迁移测试仍建立 v1 数据库并验证旧观看记录和缓存保留。队列、完成标记、续播及启动暂停沿用已有流程。

独立 `interaction.json` 增加字幕显示偏好，缺失时为双语。旧动作的自定义快捷键优先于新动作默认键；冲突的新动作不绑定，并在设置页保留提示。循环、搜索、跟随位置不持久化。偏好调整不重新加载媒体或重启对齐。

## 验证方式与证据范围

原生测试使用真正的 mpv 播放、AppKit 窗口、实际投递的键盘事件、搜索框 field editor 和表格滚动事件。时间码与循环状态多数通过 UI 共用控制入口验证；不把它们描述为物理鼠标点击全过程。表格检查包括 5,000 个英文句子和 5,000 个中文句子，以及播放期间搜索、手动滚动和回到当前句。性能数字来自本机单次运行，包含 UI 调度，并非跨硬件保证。

字幕显隐检查比较真实视频视图几何尺寸、当前字幕及词卡状态，并保存英文、无字幕、双语和 980 × 640 最小窗口截图。截图补入 OpenGL framebuffer。双窗口在同一显示器验证，不声称已经完成外接显示器物理摆放测试。

## 独立待验收项

1. 真实影视清晰对白、快速对白、背景音乐三类至少 100 词的人工起点标注，以及清晰对白 ±200 ms / 90% 目标仍待验收。现有 157 词有声书音频与合成画面仅用于技术回归，不能充当影视精度证明。
2. OpenSubtitles 线上账户、API Key、实际搜索下载联调仍待用户授权的配置；现有离线及服务错误测试不能代替线上结果。
3. 实体外接第二显示器的布局与第三方输入法人工遍历继续待检查；本次验证的是双窗口状态共享和原生编辑焦点保护。
